# Monthly review questions

These are generic public examples, not copies of private client handoffs. Select three questions relevant to the review, or use the requester’s approved set.

1. What changed for the people using the system this month?
2. What remains unfinished, and what is preventing completion?
3. What assumption turned out to be wrong?
4. Which repeated problem should we address next?
5. What information would make the next decision easier?
6. What should the next operator know before taking over?

Do not imply that an incident or success happened merely because a question mentions it.
