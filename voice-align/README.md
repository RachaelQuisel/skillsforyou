# Voice align

## Trigger

I use this skill to make a piece of writing easier to understand on the first read. It preserves the facts and removes wording that does not help the reader.

Content needs a clearer explanation, a shorter rewrite, or a review of what to keep, change, or remove.

## Inputs

- The source text and intended audience.
- The requested format and facts that must be preserved.

## What happens

1. Identify what the reader needs to know or do.
2. Start with the first useful point.
3. Use familiar words and short, complete sentences.
4. Preserve exact labels, commands, and identifiers when required.
5. Remove repeated points, filler, and unsupported certainty.
6. For process explanations, organize the content by trigger, inputs, actions, and outputs.
7. Return the revised content. Summarize changes only when requested.

## Outputs

Revised content, or a requested Keep / Change / Remove review. This public version has no external delivery requirement.

## Try it with a fictional example

Once the source skill is installed and configured, use a request like this:

```text
Use voice-align to rewrite a fictional equipment-return procedure. Keep the dates and required actions exact. Use short numbered steps.
```

## Setup and limits

The editing rules do not imitate a personal writing style. It does not log to Airtable, attach files to external records, or send Teams notifications. Those private delivery steps are excluded from this public version.
