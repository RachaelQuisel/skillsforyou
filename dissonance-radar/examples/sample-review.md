# Fictional example: an expanding launch

This is invented material to demonstrate the skill. It is not a client transcript.

## Input

### Planning meeting, March 2

00:10 - Project owner: "For Friday, we only need the intake form. Reporting can wait until the next version."

00:25 - Builder: "I can finish the form by Friday if the coordinator sends the approved questions by Wednesday."

00:40 - Coordinator: "I'll send those by Wednesday."

### Check-in, March 5

00:10 - Project owner: "For Friday, I also need reporting by region and the manager approval screen."

00:25 - Builder: "I still haven't received the approved form questions. I can work late to try to cover everything."

00:40 - Coordinator: "The manager changed the questions. I can send a draft, but I don't know who signs off now."

## Sample output

# Dissonance Radar

Sources: Planning meeting, March 2; check-in, March 5. Both are fictional excerpts supplied in this example.

Coverage: No information about capacity, later decisions, or the approval process outside these excerpts.

## 1. Which deliverables actually need to be ready by Friday?

Lens: Goals / pace mismatch

Evidence:
> Project owner: "For Friday, we only need the intake form. Reporting can wait until the next version."
> Planning meeting, March 2, 00:10

> Project owner: "For Friday, I also need reporting by region and the manager approval screen."
> Check-in, March 5, 00:10

Why ask: The requested deliverables expanded while the deadline stayed the same. Clarifying priority could change what the builder commits to; these excerpts don't establish whether the expanded scope is feasible.

Next move: Ask the project owner which deliverable takes priority before confirming the Friday scope.

## 2. Who approves the form questions now?

Lens: Roles / commitment follow-through

Evidence:
> Builder: "I can finish the form by Friday if the coordinator sends the approved questions by Wednesday."
> Planning meeting, March 2, 00:25

> Coordinator: "The manager changed the questions. I can send a draft, but I don't know who signs off now."
> Check-in, March 5, 00:40

Why ask: The delivery estimate depended on approved questions, and approval ownership is now unclear. Naming the approver could unblock the handoff or change the delivery estimate.

Next move: Ask the project owner to identify the person who can approve this version of the questions.

## Not flagged

- The builder's offer to work late doesn't establish a recurring personal pattern. The scope question addresses the visible decision without diagnosing the builder.
- No participation or sentiment change is established by these excerpts.

## Other valid outcomes

- If a complete source shows no decision-relevant signal, return a brief no-findings result.
- If the second transcript is cut off, state the missing coverage. Don't assume that a later section failed to resolve these questions.
