# Meeting prep

## Trigger

I use this skill to collect the context I need before a meeting: where the work stands, what changed, and which decisions are still open.

A meeting is approaching, or a date has been selected for preparation.

## Inputs

- Calendar access or the specific meeting details.
- Current project documents, updates, task activity, and recent transcripts.
- Public company information when the meeting is with a new prospect.

## What happens

1. Identify the meetings in scope.
2. Match each meeting to the correct project or prospect.
3. Read recent decisions, work updates, and unresolved questions.
4. For unmatched prospects, research available public company context.
5. Prepare talking points and distinguish verified facts from missing information.

## Outputs

A short brief for each meeting, covering prior context, task updates, talking points, open questions, and watch-outs.

## Try it with a fictional example

Once the source skill is installed and configured, use a request like this:

```text
Use meeting-prep for a fictional equipment-rental kickoff. I will supply the event details and project notes. Flag any information that is missing.
```

## Setup and limits

The skill needs access to its sources and the correct time zone. It does not create meetings or send messages. Supply only the calendar, project folders, and task sources you authorize for the requested meetings.
